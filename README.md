# BayKdang

Bay Kdang Brand Mak Oundy is a Vue 3 food ordering website with menu, cart, contact, and registration pages.

## Features
- Home page with hero section and featured products
- Menu page with all products
- Shopping cart with quantity controls
- Registration form
- About page with company values
- Contact page with contact information
- Bilingual support (Khmer/English)
- Mobile responsive design

## Deployment

The website is built and ready in the `dist/` folder.

To deploy:
1. Upload all files from the `dist/` folder to your web server
2. Or run `npm run preview` to test locally

### Build for production
```bash
npm run build
```

### Preview locally
```bash
npm run preview
```

### Development server
```bash
npm run dev
```
